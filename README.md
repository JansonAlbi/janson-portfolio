# Janson Albi Scaria — Personal Portfolio

This repository is a minimal, production-ready portfolio site built with React, Vite, Tailwind CSS and Framer Motion. It offers a modern, dark-themed design with smooth animations and responsive layout.

Features
- Dark theme with subtle gradients and accent colors
- Framer Motion powered animations and scroll effects
- Cursor-follow glow and smooth hover interactions
- Sections: Hero, About, Projects, Experience, Contact

Quick start (Windows PowerShell)

1. Install dependencies

```powershell
npm install
```

2. Run dev server

```powershell
npm run dev
```

Build for production

```powershell
npm run build
npm run preview
```
